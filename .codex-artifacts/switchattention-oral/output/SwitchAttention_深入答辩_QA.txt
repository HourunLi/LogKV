1. What is the main novelty compared with static hybrids or head-based methods?
你们相对静态混合、按head划分的注意力，究竟新在哪里？

英文主答
Our main contribution is a content-dependent attention choice for each token at each layer. A static hybrid fixes which layers use global attention. SwiAttn allows that choice to change across tokens within the same layer, while sharing QKV projections. Adaptive regularization learns where the cheaper local branch is sufficient.

尖锐追问
Does finer granularity actually cause the improvement, or is it just more flexibility?

英文追问回答
Our results support this learned routing design against the tested static baselines. They do not isolate granularity as the sole cause. We have not compared every alternative granularity or an optimally tuned static schedule, so we would not make that broader claim.

展开答法
直接证据是：相同额外CPT token预算下，SwiAttn优于本文的静态混合基线；NIAH中，所需信息进入窗口后，full-attention比例也明显下降。这支持学习动态分配计算的价值。
但这些结果没有单独隔离“token级路由”相对于所有替代粒度的因果贡献。论文未报告相同预算的随机路由、冻结学习后路由或完整粒度对照。不能声称每个head独立路由：当前方法每个token、每层只有一个标量gate。
依据：Slides 3、7–9；论文Figure 1、Figure 6、Table 2–3、§3.2。

2. How can the router know that global context is needed before reading it?
没有先读取全局信息，路由器怎么知道需要全局信息？

英文主答
The router predicts whether global access will be useful from the current hidden state. At higher layers, that state may already contain context gathered by earlier layers. Training encourages useful routing decisions through the language-modeling loss and adaptive regularization. It is a learned predictor, so it can make mistakes; it is not an oracle.

尖锐追问
If the needed information has never been read, how can a local hidden state reveal it?

英文追问回答
The router predicts whether to look globally; it does not need to locate the answer first. A later layer can still choose full attention after an earlier local decision. However, neither the initial decision nor later recovery is guaranteed, and routing errors remain possible.

展开答法
要区分“知道答案在哪里”和“预测这类计算是否值得查看全局”。路由器只需要学习后者，例如根据当前查询或表示选择更多全局访问，不需要先解出答案。
前层曾使用full attention时，较高层表示可能已带有全局信息；多层局部注意力也可能逐步传播信息。但如果所需信息从未进入当前表示，就不能保证路由器识别每一个需要全局访问的情况。论文Figure 6证明所测任务中的行为适应，未证明任意输入上的完美路由。
“前层信息可进入后层表示”是结构层面的解释，不能包装成论文已完成的机制归因实验。
依据：Slides 4、9；论文§3.2、Figure 6。

3. Does the use of token NLL introduce future-token leakage?
正则里用了真实下一个token的NLL，是否泄漏未来信息？

英文主答
No future token is an input to the inference router. Ground-truth NLL is used only to weight the regularizer during teacher-forced training. At inference, the gate depends on the current causal hidden state. This separates the training supervision from the information available when the model makes a routing decision.

尖锐追问
But the routing policy was learned using the answer. Why is that acceptable?

英文追问回答
Using targets to construct a training loss is standard supervised learning. The causal requirement concerns the forward inputs at prediction time. Here, the target influences the training objective, but it is not supplied to the inference gate.

展开答法
语言模型本来就利用真实下一个token构造训练损失，关键是标签不能进入该次预测的前向输入。这里NLL只用于训练目标；推理计算gate时不需要真实答案，也不计算NLL。
分支输出差异同样只是训练中的正则信号。解码阶段先从当前hidden state得到gate，再执行被选分支，不必为了决定路线先运行两个分支。
安全表述是“causal routing at inference”，不是声称训练完全不使用答案监督。
依据：Slides 4–5；论文§3.3中training-only说明、Appendix A。

4. How do you train a hard routing decision? Why use a threshold of 0.5?
离散选择怎么反向传播？0.5阈值有什么依据？

英文主答
We use a straight-through estimator. The forward pass makes a binary choice, while the backward pass uses the sigmoid surrogate to train the router. The threshold is fixed at 0.5 in our experiments. It is an operating choice in this study, rather than a threshold we have shown to be universally optimal.

尖锐追问
Does the surrogate gradient optimize the true discrete objective?

英文追问回答
It is a biased surrogate, not an unbiased gradient of the discrete objective. The forward computation still uses a hard gate, while the backward approximation makes learning practical. Our justification is empirical performance, rather than a guarantee of optimal discrete optimization.

展开答法
不应声称STE是离散目标的无偏梯度。设p=sigmoid(z)，g=1[p>0.5]+p-stopgrad(p)。前向g等于0或1；反向对z采用sigmoid的梯度。
这使训练前向和推理都使用硬选择，但梯度仍是近似。训练期间两个分支都计算，主要为这种优化方式和分支差异正则提供信息。论文没有给出STE相对所有其他离散优化方法的系统优越性结论，也未证明0.5全局最优。
依据：Slide 13 / Backup 1；论文Eq.1–6。

5. Why combine prediction difficulty and branch disagreement in the regularizer?
为什么要同时用NLL和两个分支的输出差异？

英文主答
The two signals address different concerns. NLL measures prediction difficulty, while branch disagreement measures how much the attention output changes when global access is removed. Either signal can weaken the efficiency penalty. The ablations support using both signals, although neither one guarantees that full attention is the better choice for every token.

尖锐追问
A high NLL may reflect missing knowledge, and a large MSE may be harmless. Why should either require full attention?

英文追问回答
They do not require full attention. They only relax the penalty that favors local attention. These are imperfect signals: disagreement says that the branch choice may matter, not which branch is better. The ablation provides empirical support for combining them.

展开答法
这个反驳成立，所以不要把它们称为全局需求的真实标签。高NLL不必然说明缺少远程信息；大输出差异也不必然提高最终损失。方法仅在这些情况下减弱推向SWA的惩罚，并不强制选择full。
Appendix C的Lipschitz论证只是：在相应假设下，输出差异可以控制下游损失变化的上界。较大的上界不是较大实际损失的证明，更不能证明变化方向。
Table 4中，完整方法的三项摘要均值为26.2；固定正则权重24.9；去NLL为25.3；去分支差异为24.7。这是经验支持。由于没有同时报告这些变体的路由量，不能声称是严格相同计算预算下的收益。
依据：Slides 5、14；论文Eq.7–8、Table 4、Appendix C。

6. If training computes both branches, does it double the cost? Is this a cheap conversion?
训练两个分支会不会翻倍？所谓转化成本低到底有多低？

英文主答
Computing both attention branches does not duplicate the entire transformer layer. They share QKV projections and the remaining components. At 32K, the reported per-layer CPT overhead is 8.4 percent for the forward pass and 7.9 percent for the backward pass. However, conversion still requires substantial continual pretraining, with the whole model updated.

尖锐追问
Eight or twenty billion extra tokens are still expensive. What does “efficient adaptation” mean here?

英文追问回答
The advantage is reusing an existing model instead of training this architecture from scratch. It is still whole-model continual pretraining, not a router-only or training-free conversion. The additional token budget and the per-layer overhead should be reported separately.

展开答法
“每层运行时间开销”和“总CPT预算”是两个不同问题。前者约8%；后者在4K模型上为20B tokens，在32K模型上为8B tokens，分别约占对应先前训练token预算的8.3%和3.7%。这些比例不是等比例的FLOPs或总费用估计。
优势是从已有FullAttn模型初始化，避免为这个结构从零重训；这不是只训练一个小router，也不是无需训练的即插即用替换。不要把20B/8B说成免费或极少量适配。
依据：Slides 6、11；论文§3.4、Appendix F、Table 8。

7. Do the 4.4× and 12× numbers mean real inference speedups?
4.4倍、12倍是不是实际推理加速？

英文主答
These numbers describe reduced KV-token access during decoding. At 32K, the average changes from 32K tokens to 7.3K in the standard setting and 2.6K in the simple setting. We do not report an end-to-end latency speedup. Runtime also depends on routing overhead, memory reuse, kernel execution, and the rest of the model.

尖锐追问
Without a latency benchmark, how strong is the efficiency claim?

英文追问回答
The evidence supports lower attention work and logical KV access, but not a measured application-level speedup. Relative to the static hybrid, access falls from 8.0K to 7.3K in the standard setting, about 9 percent, and to 2.6K in the simple setting, about 68 percent. The gain therefore depends on the comparison and input distribution.

展开答法
当前证据支持的是注意力计算量和逻辑KV访问量下降，以及存在相应kernel实现；它没有完成系统级速度收益的验证。即使注意力访问减少4.4倍，FFN、投影和其他开销也没有按相同比例下降，因此不能外推整个模型加速4.4倍。
simple设置是needle位于sliding window内的NIAH输入；约12倍是特定输入分布下的结果。标准设置下更有代表性的报告值是4.4倍。
若追问物理带宽：论文以被访问的KV token数量为度量，不能称为实测HBM流量降低同样倍数。缓存复用、tile冗余和batching均可能改变物理传输量。
与已经较省的SH比较，标准设置是8.0K→7.3K，约减少9%；simple设置是8.0K→2.6K，约减少68%。4.4倍和约12倍的分母是FullAttn，不能换成SH。
依据：Slide 10；论文Figure 4(b)、§4.4、Appendix K。

8. Does SwiAttn reduce KV-cache memory or change the asymptotic complexity?
是否节省KV缓存容量？是否从二次复杂度变成线性？

英文主答
The method reduces the KV history read by local queries, but it retains the full shared cache for possible future global queries. Cache capacity therefore still grows linearly with context length. A fixed nonzero fraction of full-attention queries also preserves quadratic prefill complexity. The benefit is reduced work under the learned routing distribution.

尖锐追问
If a token chooses local attention now, why not discard its old keys and values?

英文追问回答
A local decision applies to the current query. It does not make old keys and values irrelevant to future queries, which may choose global attention. Discarding them would require an additional eviction or compression policy that this work does not evaluate.

展开答法
当前token选择局部注意力，不代表未来token或后续解码步骤不再需要某段历史。也不能因为某个历史token当时走了SWA，就认为它的K/V不会被未来full-attention查询使用。
在固定模型尺寸下，如果长度N、窗口w、full查询比例近似固定为p，则prefill工作量可用O(pN²+(1-p)Nw)解释；p为正常数时仍然是O(N²)。单步decode的理想逻辑访问量约为pN+(1-p)w，完整缓存容量仍为O(N)。这是简化推导，不是论文提供的最坏情况改善定理。
要实际缩小缓存容量，需要额外的淘汰、压缩或结构约束；当前论文没有建立相应保证。
依据：Slides 4、10–11；论文Appendix A、Limitations。

9. Can fine-grained routing run efficiently on hardware?
如此细粒度的分支选择，会不会让硬件执行变慢？

英文主答
The prefill kernel groups routed queries into separate position-sorted lists and processes them in query tiles. This provides KV reuse across query positions, rather than relying only on a large GQA group. It addresses an important execution issue, but index construction, gather and scatter, and irregular workloads still affect actual runtime.

尖锐追问
Does the arithmetic-intensity argument guarantee a speedup, especially for decoding?

英文追问回答
No. It explains a reuse opportunity in the proposed prefill tiling. It does not account for every execution cost, and it is not a decoding latency measurement. Routing distributions, batching, masking, and kernel overhead still determine realized performance.

展开答法
不保证。论文的推导针对相应prefill tiling和主导IO记账：当KV跨度S足够大时，算术强度约受query tile大小Bq控制。它说明一种复用机制，不是完整roofline预测，更不是解码性能实测。
位置排序并不使查询变成连续位置。尤其是SWA分支，一个tile中各查询的局部窗口可能分散，实际覆盖的KV范围和masked计算也会影响效率。batch、路由分布和kernel实现都重要。
不要把“可与PagedAttention、Split-KV结合”说成论文已经完成这些系统的集成与端到端对比。
依据：Slide 17 / Backup 5；论文§3.5、Eq.10–11、Appendix B。

10. Are the comparisons fair if SwiAttn receives additional pretraining?
你们比FullAttn多训练了，效果保持是不是额外训练的功劳？

英文主答
The static hybrids and SWA-CPT receive the same additional token budget as SwiAttn, so those comparisons control for added training data volume. The FullAttn reference does not receive that extra CPT. We therefore interpret the FullAttn comparison as recovery of the source model’s quality after conversion, rather than a strict equal-total-compute comparison.

尖锐追问
Would a full-attention model trained for the extra eight billion tokens perform better?

英文追问回答
It might; we do not report that control. Our strongest comparison is against the converted baselines with the same extra token budget. Even there, equal tokens do not imply equal training FLOPs, because SwiAttn computes both branches during training.

展开答法
可能，现有实验不能排除，不能替未做的对照报结果。
较强的证据是：在相同额外token预算的已测适配基线中，SwiAttn的检索52.9高于SH(3:1)的50.6，LongBench-E的37.4高于35.2。与FullAttn的同均值则说明转化后恢复了源模型参考质量。
相同token预算也不等于相同训练FLOPs或wall-clock，因为训练时两分支都计算。完整的质量—训练成本—推理成本比较，需要另行定义匹配口径；本次答辩应承认当前比较边界。
如果被追问是否比较了最优静态布局：只比较了论文所列3:1、6:1等配置，没有证明它们是所有静态布局中的最优解。
依据：Slides 6–8；论文Appendix F、Table 2–3。

11. Does the same average score establish lossless quality or statistical equivalence?
平均分相同是否意味着无损？p=0.941是否证明等价？

英文主答
We report the same rounded aggregate scores for the main 1.5B retrieval and LongBench-E evaluations. Individual tasks still differ. The statistical analysis finds significant improvements over SH on retrieval and LongBench-E, but a non-significant difference from FullAttn does not prove equivalence. Our claim is similar observed aggregate performance under this setup.

尖锐追问
Could the average hide meaningful regressions?

英文追问回答
Yes. For example, Qasper changes from 18.6 to 18.0 and TREC from 63.7 to 60.0, with improvements elsewhere offsetting them. We should describe the result as a matched reported average, not preservation on every task or a statistical equivalence guarantee.

展开答法
会。Table 3中，SwiAttn的Qasper为18.0，对照18.6；TREC为60.0，对照63.7；其他任务的提升抵消了这些下降。正式展示应说“same reported average”，不要说“every task is preserved”。
Table 10报告三次run及Welch t检验：相对SH，retrieval为p<0.001，LongBench-E为p<0.01；相对FullAttn，LongBench-E为p=0.941。后者只表示该检验没有检出差异，不能代替预设等价界值的等效性检验。
材料没有明确三次run是否为三次独立训练种子，因此不要自行表述成“已完成三个training seeds”。
不应把若干异质任务的平均值当成所有实际应用都有相同收益的保证。
依据：Slides 8、18；论文Table 3、Table 10。

12. Why does a 13% full-attention ratio not imply only about 13% KV access?
如果只有13%的full attention，为什么32K时还要读取7.3K？

英文主答
The two numbers summarize different measurements. Thirteen percent is averaged across layers and positions over 400 million tokens from the CPT distribution. The 7.3K figure describes decoding access at a 32K position. Local attention also reads its window. We should not substitute a global routing average for the routing distribution of that decoding measurement.

尖锐追问
Can you at least explain the expected relationship between routing and KV access?

英文追问回答
At a fixed context length, a simplified estimate is the full-route fraction times the context length, plus the local-route fraction times the window size. The routing fraction must come from the same samples and averaging scheme. The paper does not report the exact position-conditioned fraction needed to reproduce 7.3K from the 13 percent statistic.

展开答法
如果固定上下文长度N，并用与访问量完全相同样本、位置、层和权重的full比例p，那么理想逻辑读量约为A=pN+(1-p)min(w,N)。当N为32K、w约1K时，p=0.13给出约5K，而不是7.3K；这正说明不能直接混用统计口径。
反过来，用7.3K代入这个简化模型，会得到约20%的有效full比例，但它只是按四舍五入访问量反推的解释，不是论文独立报告的路由实测值。无需在台上主动报这个反推值。
另一个易错点：SH(3:1)的25%是名义周期。本文22层实际只有5个full层，比例为5/22≈22.7%。
依据：Slides 9–10；论文Figure 4–5、Appendix E。

13. Does 100% needle retrieval establish general long-context capability?
NIAH达到100%，能否说明长上下文能力没有损失？

英文主答
The result establishes perfect retrieval within the tested NIAH configuration: 35 context lengths, 35 needle positions, and three repetitions. It is useful evidence that distant information remains accessible. It does not establish performance on every long-context task, so we also report natural-language retrieval and selected LongBench-E tasks.

尖锐追问
Why not evaluate the full LongBench-E suite or harder multi-hop and code tasks?

英文追问回答
Our evaluation covers seven selected LongBench-E datasets, not the entire suite. Multi-hop and code tasks are outside the reported coverage, so we cannot claim the same results there. The NIAH result is controlled retrieval evidence, not a substitute for those evaluations.

展开答法
现有LongBench-E结果覆盖论文明确选择的7个数据集，主要涉及问答、摘要和few-shot任务；不是整个评测集合。Appendix D列明没有覆盖HotpotQA、2WikiMultihopQA等多跳QA，以及代码补全等子任务。
可以说这是研究范围选择，但不能编造“其他任务不相关”“结果也一样好”或“已经验证过”作为理由。NIAH是受控检索证据，不能替代多跳推理、代码、任意干扰输入或超过32K的验证。
Figure 6中路由与needle位置的联系支持所测条件下的适应性，但不构成严格的机制因果证明。
依据：Slides 9、16；论文Figure 3、Figure 6、Table 7、Appendix D.3。

14. Does the method scale beyond 1.5B parameters?
小模型有效，放到更大模型还能保持吗？

英文主答
We include a preliminary 3B evaluation with the same hyperparameters and training schedule. Retrieval changes from 55.4 to 55.8, while the five-task LongBench-E average changes from 37.2 to 36.6. This shows that the approach can be applied at 3B, but it does not establish lossless scaling or results at larger industrial model sizes.

尖锐追问
Does the 0.6-point long-context drop suggest the approach does not scale?

英文追问回答
It shows that exact parity did not hold in this 3B setting. One model size and configuration are insufficient to establish a general scaling trend in either direction. We should report the drop directly without assuming that further tuning would remove it.

展开答法
它说明3B设置没有重现主实验完全相同的长文本均值，值得如实呈现；仅凭这一个规模和一个设置，也不能证明方法无法继续扩展。
论文没有做专门的规模调参，所以“相同配置可运行”是事实；“调参一定能补回差距”是未验证假设，不能混淆。注意3B只算5个LongBench-E任务，1.5B算7个，两个绝对均值不能直接拿来比较规模趋势。
依据：Slides 11、15；论文Appendix I、Table 5–6、Limitations。

15. How do you control the compute budget, and how sensitive is the method to hyperparameters?
计算预算怎么控制？窗口和正则参数是否需要大量调节？

英文主答
The full-attention ratio is learned rather than enforced as a hard budget. The base regularization weight controls the pressure toward local attention, while the window size determines the local context range. Our experiments use a 1,024-token window and fixed settings. The reported ablations cover some regularization parameters, but not a complete deployment tradeoff curve.

尖锐追问
Can I set a desired latency or halve the full-attention ratio after training?

英文追问回答
Not with a guarantee from the current results. The regularizer encourages lower use of full attention, but it does not enforce a precise routing ratio or latency. Changing the inference threshold would also change routing, but its quality–efficiency tradeoff has not been established here.

展开答法
不能承诺。增加γ_base会加强训练中推向SWA的压力，但它不保证准确命中某个full比例，更不直接控制wall-clock latency；输入分布也会改变最终选择。
推理时改阈值原则上会改变选择频率，但论文没有给出相应质量—效率曲线，因此不能宣传无需重新适配的预算旋钮。
Table 4中α、ε的变化影响摘要均值；没有完整窗口大小扫描，也没有所有变体的路由比例或成本数据。可复用的主张是已有模型能通过CPT学习这种分配，而非所有模型、窗口和预算都无需重新校准。
依据：Slides 5–6、14；论文§3.3、§4.1、Table 4。

16. Are NLL and branch MSE detached when computing the adaptive weight?
γ的分母是否参与反向传播？会不会通过增大NLL或分支差异来降低正则？

状态：实现待作者确认。以下不能当作训练实现的既定事实。

英文主答（在尚未确认实现时）
The paper explicitly specifies the stop-gradient operation for the straight-through gate, but it does not specify the gradient treatment of the adaptive weight. I would need to check the training implementation to answer that precisely. The important distinction is whether NLL and branch disagreement act only as weighting signals or also receive gradients from this regularizer.

尖锐追问
If the denominator receives gradients, does the model have an incentive to make prediction worse?

英文追问回答（条件分析，不是实现声明）
For the regularizer alone, increasing the denominator reduces its value, so a non-detached denominator introduces that gradient path. However, the total objective also penalizes prediction error. We need the actual gradient treatment and weighting to assess the interaction; the formula alone does not establish that training exploits it.

展开答法
从公式L_reg=c·softplus(z)/(ε+NLL+αD)看，在其他量固定时，增大NLL或D确实会降低这个正则项。如果分母没有停止梯度，正则对这些量会产生额外梯度路径；其中对NLL的偏导为负。
但不能据此直接断言总训练目标必然鼓励更差预测，因为语言模型损失自身仍惩罚NLL，所有量也共享参数、相互耦合。需要看实际detach位置、归一化和权重，才能判断总梯度。
如果实现对NLL与D都detach，可以明确回答它们只决定权重，模型不能沿分母梯度降低这个正则项。如果没有detach，就如实说明联合优化耦合，不能沿用“只是固定权重”的解释。部分detach也需分别说明。
